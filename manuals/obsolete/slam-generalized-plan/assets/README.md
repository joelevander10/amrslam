# Architecture diagram image assets

Place the cropped EDC IUV vehicle image at:

`edc-iuv-vehicle.png`

Recommended preparation:

- Crop to the vehicle only; do not include the surrounding presentation slide.
- Prefer a transparent PNG or a white-background image.
- Use at least 800 × 450 px so it remains sharp in the 16:9 diagram.
- Keep the vehicle facing the same direction as the original EDC reference.

The image is consumed by `../edc-iuv-architecture-diagrams.html`. When it is
missing, the page shows an explicit placeholder instead of a broken-image icon.
